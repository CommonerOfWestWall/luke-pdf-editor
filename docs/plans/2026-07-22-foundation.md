# 鲁科 PDF 编辑器基础内测里程碑实施计划

**目标：** 建立可运行、可测试、真实使用 MuPDF 的 Windows PDF 查看与批注垂直切片。

本里程碑仅供内部技术验证，不生成安装包、不对外发布，也不代表产品完成。项目完成标准是功能矩阵中适用的 PDF‑XChange Viewer/Editor 基线能力全部达到交叉兼容验收。

## 里程碑 0.1

- [x] 初始化 React、TypeScript、Vite、Tauri 2 和 AGPL 项目。
- [x] 建立 MuPDF Worker RPC 与内部稳定类型。
- [x] 接通打开、渲染、文本提取、搜索、批注和导出接口。
- [x] 实现 Rust 受限文件会话、二进制读写和 Windows 原子替换。
- [x] 实现现代命令栏、导航栏、页面区、评论栏和明暗主题。
- [x] 生成原创像素马喽阅读 PDF 应用图标并导出 Windows 图标资源。
- [x] 增加坐标和批注命令单元测试。
- [ ] 使用测试 PDF 完成 Tauri 端到端打开、创建便签、保存、重开验证。
- [ ] 为密码 PDF 增加密码输入流程。

## 门禁

1. 自动测试和开发构建全部通过。
2. 使用合法测试语料完成浏览器内测和桌面开发版内测。
3. 当前批次所有数据写回功能完成保存后重开验证。
4. Critical/Important 代码审查问题清零后才进入下一批。
5. 安装包、自动更新和外测只在功能冻结后的发布候选阶段开启。
