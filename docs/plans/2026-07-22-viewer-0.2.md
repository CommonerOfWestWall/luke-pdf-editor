# 查看器 0.2 内测实施计划

**目标：** 从单页技术切片演进为可处理长文档的连续阅读器，并补齐密码文档、文本层和搜索导航。

## 0.2a：长文档阅读基础

- [x] 密码 PDF 输入、错误反馈、取消与重试；失败打开不得破坏当前文档。
- [x] 连续页面滚动，视口前后只渲染有限缓冲页。
- [x] 页面渲染任务支持过期结果丢弃，缓存按文档、缩放、旋转和修订隔离。
- [x] 页码、缩略图点击和搜索定位与滚动位置双向同步。
- [x] 200/1000 页文档不预渲染全部页面，并记录峰值缓存页数。

## 0.2b：文本与搜索

- [x] StructuredText 文本层支持选择和复制，并遵守复制权限。
- [x] 搜索结果高亮、上一个/下一个、结果计数和循环导航。
- [x] 链接识别与受控外部打开。
- [x] 页面旋转、缩放、高 DPI 下文本层与搜索四边形视觉回归。

## 内测门禁

- 自动测试覆盖密码状态、渲染缓存淘汰、可见页计算和搜索结果导航。
- 真实测试包含加密 PDF、200 页文本 PDF、1000 页 PDF、扫描 PDF 和密集批注 PDF。
- 浏览器内测无未处理异常；桌面开发版完成打开、连续滚动、搜索、保存和重开。
- 本批次不生成安装包；全部 Important 审查问题关闭后才进入批注 Beta。
