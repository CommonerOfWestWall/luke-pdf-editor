## 应保留的工作流原则

1. **全局任务与上下文工具分层。** 文件、查看、批注、页面等任务有稳定入口，当前任务再展开相关工具，降低跨功能寻找成本。
2. **文档、面板和状态栏各司其职。** 页面保持主视觉中心；导航、评论、属性使用可开关侧栏；页码、缩放和状态固定在边缘。
3. **属性随选择变化。** 选中批注或内容后才显示相关字段，避免把所有属性永久堆在顶部。
4. **命令可搜索。** Quick Launch 让不记得菜单位置的用户仍能快速执行命令，也为键盘重度用户提供稳定路径。
5. **高密度但可定制。** 专业用户需要高命令密度，但必须通过工作区、面板开关、快捷键和显示密度管理复杂度。

## 鲁科的改进方向

| 观察 | PDF-XChange 的优势 | 鲁科当前处理 | 后续门禁 |
|---|---|---|---|
| 顶部命令层 | 功能完整、分类清楚 | 两级紧凑栏：工作区模式 + 全局命令；空状态总高度约 130px | 任何新增工具不得无条件增高顶部区域 |
| 批注工具 | 类型集中、发现性强 | 批注工作区显示文字标记、便签、文本框、绘图分组；未实现项明确禁用 | 工具只有在完成真实 PDF 往返后才能启用 |
| 评论面板 | 按页聚合、回复直接 | 全文/当前页、类型和文本筛选；选中后在同栏编辑属性 | 0.3d 增加回复树、状态和批量操作 |
| 属性面板 | 与当前对象同步 | 属性编辑嵌入评论栏，减少独立面板占宽 | 0.3c 图形工具再评估独立属性检查器 |
| 命令查找 | Quick Launch 可发现大量命令 | `Ctrl+K` 命令搜索，支持关键词、禁用态、方向键和 Enter | 新命令必须进入命令目录并具有可访问名称 |

## 视觉与可访问性判断

- 采用深色中性底、低饱和边界和琥珀色单一强调色；图标与文本不过度彩色化，文档始终是视觉中心。
- 相比参考界面减少大图标组和多层边框；选择态同时使用颜色、底色和边框，不只依赖颜色。
- 当前 1280×720 截图无裁切；命令搜索遮罩和焦点结果可辨识。
- 参考界面中存在较小文字和密集点击目标。鲁科仍需在 200% UI 缩放、键盘焦点顺序和触控密度上单独验收；截图不能替代屏幕阅读器测试。
