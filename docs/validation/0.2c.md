# 真实页面缩略图 0.2c 内测记录

验证日期：2026-07-22

## 真实样本

- 测试文件为用户提供的 170 页、约 20.8 MiB 审读批注 PDF；测试只读取工作区临时副本，不修改原件。
- 首屏 600px 高缩略图面板挂载 7 个按钮并得到 7 张真实 MuPDF 页面预览；渲染失败 0。
- 跳转到第 170 页后挂载 10 个按钮、得到 10 张预览；没有创建全部 170 页的图片或 DOM 节点。
- 旋转前页面预览为 89×126，旋转 90° 后为 144×102，页面没有拉伸；旋转后渲染失败 0。

## 实现门禁

- 缩略图与正文共用唯一 `PdfClient`/MuPDF Worker，不引入第二 PDF 引擎。
- 可见窗口为单列、164px 行高、3 行过扫描；600px 高面板测试约束最多 12 个按钮。
- 缩略图请求延迟 80ms 并按可见优先级错峰，避免打开文档时抢在正文首屏前批量提交。
- 缓存 key 包含文档代次、渲染修订、页码、栅格比例和旋转；缓存预算 24 MiB。
- 卸载或 key 变化后忽略迟到结果；Blob URL 在结果变化与卸载时释放；单页失败只显示“预览失败”。
