# 0.3a 全文批注审阅验证记录

日期：2026-07-22

## 本批实现

- Worker 增加全文批注扫描，逐页释放 PDF 页面和批注包装对象。
- 右侧面板支持全文/当前页、批注类型以及作者/内容/页码组合筛选。
- 点击评论更新当前页；选中态具有键盘焦点和可访问名称。
- 属性编辑支持内容、作者、主题、颜色和透明度；未改颜色保留原 PDF 颜色空间。
- 锁定批注和禁止批注权限下只读；删除要求确认，并复用 MuPDF journal 撤销/重做。
- 新文档、删除和异步刷新会清除失效选择；旧请求结果不能覆盖新文档状态。

- 原文件 SHA-256：`d77c4b81b307509a8e5ec2c06534ec628d8400a9b9340c0f7f4a5a04380df660`。
- 读取结果：380 页、253 条受支持批注，均为 Highlight；第 5 页存在验收目标。
- 临时副本直接通过 MuPDF 更新内容、作者、主题、RGB 颜色和透明度后保存并重开：253 条批注保持；目标 Rect、QuadPoints、创建时间和 flags 保持；其余 252 条批注结构快照保持。
- 临时副本删除/撤销/重做计数：`252 → 253 → 252`。
- 原文件测试前后 SHA-256 一致；临时导出文件已删除。
- 此脚本验证 MuPDF 引擎行为和样本兼容性，不经过 `PdfClient`/Worker RPC/坐标与身份查找，不能替代应用 E2E。

- 通过浏览器版应用实际 `PdfClient` 创建专用 Worker，经 Worker RPC 调用 MuPDF/WASM；不是直接调用 MuPDF 的旁路脚本。
- 打开同一 380 页样本副本，读取 253 条 Highlight；验收目标位于第 5 页。

- 测试后再次核对用户原件 SHA-256，仍为 `d77c4b81b307509a8e5ec2c06534ec628d8400a9b9340c0f7f4a5a04380df660`。

## Tauri WebView 自动内测

- Windows 截图自动化仍返回 `SetIsBorderRequired failed: 0x80004002`，因此改用 Tauri 官方推荐的 embedded WebDriver 路线；测试插件只在 debug + Cargo `e2e` feature 下注册，release + `e2e` 在编译期拒绝。
- `npm run test:e2e:build` 成功生成无安装包的 E2E 调试二进制；默认 Cargo 依赖树不含 `tauri-plugin-wdio-webdriver`。
- `npm run test:e2e` 会先重建测试二进制、选择一次性空闲本地端口，并核对本次随机运行标识，避免旧二进制或遗留进程造成误通过。
- WebDriver 将样本分块传入 WebView 并构造浏览器 `File`，随后通过正式文件输入与 `PdfClient`/Worker 只读加载；断言文件名、380 页、全文 253 条批注，筛选 Highlight 后仍为 253 条，点击第 5 页批注后状态栏定位到 `5 / 380`，属性编辑器与内容输入区可见。
- 稳定用例 1 项通过，约 7 秒；服务自动结束应用进程。原文件未通过原生会话打开，因此本用例不能写回用户原件。
- 普通无 `e2e` feature 的 `tauri build --debug --no-bundle` 随后重新构建通过，确认日常二进制不注册测试服务器。
