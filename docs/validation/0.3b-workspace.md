# 0.3 工作区与命令搜索内测记录

日期：2026-07-22

## 本批实现

- 增加阅读/批注工作区模式；页面与表单入口保持禁用并明确标注计划中，不伪装为已完成能力。
- 批注工作区增加上下文工具分组；当前只启用已完成往返能力的快速便签，其余工具保持禁用。
- 增加 `Ctrl+K` 命令搜索，支持中文标签、类别/替代关键词、禁用态、方向键循环选择、Enter 执行和 Esc 关闭。
- 顶部从大 Ribbon 收敛为紧凑的工作区栏与全局命令栏，保留导航、评论面板和底部状态区。

## 浏览器内测

- 在 1280×720 内置浏览器中检查阅读空状态、批注上下文栏与命令搜索遮罩，无顶部或底部裁切。
- 从“搜索命令”输入“批注”，结果包含“切换到批注工作区”；按 Enter 后命令面板关闭、批注模式 `aria-pressed=true`，上下文工具栏可见。
- 未打开文档时，添加便签、文字标记、文本框和图形工具保持禁用；没有把计划功能暴露为可操作按钮。
- 与同轮采集的 PDF-XChange 官方工作区和评论栏截图并排检查：保留任务分层、上下文工具、侧栏和命令搜索原则，同时显著减少顶部占高和视觉噪声。
