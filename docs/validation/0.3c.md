## Task 1 实现

- `src/pdf/drawing-tools.ts`
  - `normalizePointerPressure`：鼠标固定压力；触笔压力钳制；非有限输入安全回退。
  - `sampleStroke`：去除过密中间事件，同时保留首点、最终指针位置和最终压力；不冒充曲线简化器。
  - `buildDrawingGeometry`：为 Ink、Line、Arrow、Rectangle、Ellipse、Polygon、Polyline 生成标准记录所需的 `rect`、`points` 或 `strokes`，拒绝退化几何。
- `src/pdf/drawing-tools.test.ts`
  - 覆盖鼠标/触笔压力、密集事件采样、重复点、反向拖动、端点方向、最小可见尺寸、多边形/折线顶点数。
  - 覆盖 `/Rotate 90` 与非零 CropBox 坐标空间中的页面点往返，确保输入内核只接收统一 PDF 坐标。
