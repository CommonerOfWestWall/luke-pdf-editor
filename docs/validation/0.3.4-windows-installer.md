## 已知限制

- 安装包尚未进行 Authenticode 代码签名，Windows 可能显示未知发布者警告。
- Windows 10/11 均要求用户在系统界面确认默认 PDF 应用；这是平台安全模型，不应通过写 `UserChoice` 绕过。
- Explorer 首页缩略图只随本应用 ProgID 生效；没有将处理器全局强加给其他 PDF 阅读器。
- 该包仅用于当前功能批次外测，不能据此宣称已完整替代 PDF-XChange。
