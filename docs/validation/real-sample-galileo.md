# 《工程师伽利略》审读批注样本内测

验证日期：2026-07-22

## 样本概况

- 文件大小 21,766,386 字节，共 380 页，未加密，全部页面无内建旋转且显示尺寸一致。
- 375 页含可提取文本，共 253 条标准 Highlight 批注，无外部或内部链接。
- MuPDF 全页扫描统计耗时约 700 ms（不含 UI 渲染）。

## 实际使用验证

- Edge 自动化会话打开文件成功；包含自动化进程开销的上传命令约 2.1 秒返回。
- 初始视口只挂载 3 个页面，缩略图窗口为 18 个节点；直接滚到末页后仅保留 2 个页面图像和 2 个文本层。
- 页标签（如 `a1`）正确保留；点击第 5 个物理页后显示该页的原位高亮和完整批注正文。
- 全文搜索“伽利略”得到 1,934 个结果并定位首个结果；380 页完整搜索在数秒内完成，主线程无控制台错误。
- 直接跳到第 380 页后创建标准便签并下载导出副本。结构复查仍为 380 页、253 条 Highlight，新增 1 条 Text 及其 Popup。
- 关闭并重开导出副本，末页便签作者、正文和时间均保持；源文件未被覆盖。

## 本次发现并修复

- 源 Highlight 没有 `/M` 与 `/CreationDate`，MuPDF getter 会给出 epoch。Worker 现先检查 PDF 字典键；缺失日期在 UI 中留空，不再误显示为 1970 年。
- 光栅预算触顶后缓存键曾继续使用视觉缩放值，导致相同 1600 万像素光栅重复渲染。缓存身份现使用实际 `rasterScale`，相邻高倍缩放可复用同一位图。
- 批注定位曾在遍历密集批注时依赖 GC 回收 `PDFObject`。现每次读取对象号后立即释放，避免编辑 253 条批注页面时积累 WASM 引用。
