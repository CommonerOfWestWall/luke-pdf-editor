## 真实 PDF 往返

使用两页、含可搜索文字的本地测试 PDF，通过 Edge 驱动前端执行：

1. 打开 PDF，确认 MuPDF Worker 渲染第 1 页。
2. 创建一个标准 Text 便签批注。
3. 导出 PDF；浏览器控制台无错误。
4. 重新打开导出文件，确认页数仍为 2，批注作者、正文、页码和类型仍可读取。
5. 搜索 `monkey`，确认报告 1 个结果并跳转到第 2 页。
6. 新增第二个便签后执行撤销和重做，当前页批注数依次为 2、1、2。
7. 在已有文档上尝试打开畸形 PDF，错误被显示且原文档会话和已有批注保持可用。
8. 在脏文档上触发“打开”，取消放弃修改确认后，原文档和 2 条批注保持不变。
