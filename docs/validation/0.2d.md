# 统一页面渲染调度 0.2d 内测记录

验证日期：2026-07-22

## 调度语义

- 单个 `PdfClient` 任意时刻最多向 MuPDF Worker 提交一个页面光栅任务。
- 优先级固定为正文可见页、正文缓冲页、缩略图；同优先级按提交顺序执行。
- 相同完整身份 key 的调用共享一个底层任务；每个调用保留独立订阅，取消一个订阅不会误伤其他订阅。
- 最后一个订阅取消后，尚未开始的任务从队列移除；已经进入同步 WASM 的任务继续完成，但结果不再交付给已取消订阅。
- 每个请求携带文档/修订作用域。打开、关闭或实际编辑成功后永久退休旧作用域；生命周期 RPC 期间到达的旧请求不会跨状态执行。
- 打开或编辑失败、撤销/重做无变化时回滚闸门，被取消的原页面会自动重新排队，不会永久停在骨架屏。
- Worker 终止会永久失效当前作用域；旧在途任务完成前，新作用域任务仍等待，因此不会并发进入同一 Worker。

- 快速跳到索引 119（第 120 个页面）并立即旋转 90° 后，活动页保持 119，正文图片与页面容器均为 578×410，没有闪现旧方向图片。
- 快速交互稳定后：底层任务完成 27、重复请求合并 2、订阅取消 11；缩略图挂载及成功渲染 11/11，失败 0，浏览器错误/警告 0。
- 测试同时发现并修复了旋转改变全部页面高度后滚动位置漂移的问题：布局变化现在在绘制前重新定位当前页，自然滚动仍不会被强制吸回。

## 已知限制

- MuPDF.js 当前页面光栅调用在 Worker 内同步执行，无法在不终止整个 Worker/文档会话的情况下安全中断；本批只保证取消排队任务和丢弃在途任务订阅结果。
- 正文已渲染位图降采样复用为缩略图尚未实现。
- 调度统计当前通过开发接口和内测页读取，尚未加入面向用户的诊断界面。
