# 查看器 0.2b 内测记录

验证日期：2026-07-22

## 文本层与搜索

- 两页文本样本只为当前缓冲页生成 StructuredText 层；选择后可得到页面实际文字。
- 搜索 `PDF` 得到 4 个结果，状态从 `1 / 4` 前进到 `2 / 4`，活动高亮始终唯一。
- 搜索第二页独有的 `monkey` 后定位到 `2 / 2`，活动高亮为 1 个，控制台 0 错误。
- 100% 深色主题与 120% 浅色主题、0°/90° 页面旋转均人工检查，高亮与文字重合。
- Edge 高 DPI 独立会话以 `devicePixelRatio = 2` 打开同一样本，8 个文本行节点和搜索高亮位置正常，截图人工检查通过。
- 使用非零 MediaBox/CropBox 原点且 `/Rotate=90` 的独立样本验证规范坐标；页面显示为 600×500，逐字符选择层与页面竖向文字重合。跨三条竖向文本拖选后复制得到三行文本，换行保持。
- StructuredText 使用逐字符 quad 生成仿射 CSS 热区；搜索保留四边形并以 polygon 高亮，不再把旋转或斜切文字降为水平矩形。
- 旋转样本创建便签后导出、关闭并重开，便签几何、作者和内容保持，评论栏仍为 1 条。
- 单页光栅设置 1600 万像素和 8192 像素边长上限；A0 工程图在 400% + DPR2 的请求由单元测试确认会降采样，CSS 显示尺寸不变。

## 链接

- 本地两页样本包含一个 HTTPS 外链和一个内部页链接；两个热区均被识别。
- 内部链接点击后从 `1 / 2` 定位到 `2 / 2`。
- 外部链接点击前显示包含完整 URL 的确认框；取消后没有打开新页面。
- React 与 Rust 均只允许 `http`、`https`、`mailto`，自动测试拒绝 `javascript:`、`data:` 与 `file:`。
- 浏览器用包含 `javascript:` 链接的 PDF 实测：点击后不出现确认框、不打开标签页，并显示“已阻止”错误。
