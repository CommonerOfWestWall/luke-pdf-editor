# 查看器 0.2a 内测记录

验证日期：2026-07-22

## 密码 PDF

- 使用 AES-256 加密的两页本地测试 PDF，Poppler 以正确密码渲染后人工确认页面清晰完整。
- 浏览器内测打开加密文件后显示模态密码框，不在标题栏或日志中暴露密码。
- 输入错误密码时保持对话框并显示可访问的错误信息，控制台无错误。
- 输入正确密码后成功渲染第 1 页，页数为 2，搜索和批注权限可用。
- 再次打开加密文件并取消密码框后，当前文档保持可用。
- 密码框打开时 `Ctrl+O` 等文档级快捷键被拦截，密码不会串到另一个候选文档；空闲时 `Esc` 可取消。
- 验证请求进行中禁止取消，避免 MuPDF 已打开新文档但界面误认为已取消的竞态。

测试样本、解密密码和渲染图片只保存在被 Git 忽略的 `work/` 目录，不进入仓库。

## 长文档与虚拟化

- 使用本地生成的 1000 页文本 PDF，在浏览器内打开后首屏仅有 2 个页面图像；未将 1000 页预渲染为图片。
- 滚动到文档中段后，当前页为 501，页面图像节点峰值为 4；左侧缩略图同步到 485–508 页区间。
- 左侧缩略图首屏只保留 18 个节点，中段滚动时保留 24 个节点，不再为 1000 页常驻 1000 个按钮。
- 页面渲染缓存上限为 96 MiB，按文档会话、修订、页码、缩放和旋转隔离；过期异步结果在组件卸载后丢弃。
- 中段滚动截图人工确认页面、页码和选中缩略图一致；浏览器控制台为 0 个错误。
- 从普通 PDF 切换到 1000 页 PDF 的文档切换瞬间，旧页面图像节点为 0，随后只出现 2 个新页面图像，未闪现上一份文档内容。
- 从千页文档第 501 页切换到两页文档后稳定回到 `1 / 2`，旧文档可见页状态没有越界进入新文档。
- 将千页缩略图面板独立滚到中段后打开两页文档，面板滚动位置恢复为 0，只显示 2 个缩略图。

## 保存点与撤销状态

- 创建便签后显示未保存；浏览器保存完成后恢复为已保存状态。
- 从保存点撤销后重新显示未保存，重做到保存点后恢复为已保存。
- 从保存点撤销后创建新分支操作仍保持未保存，未因相同历史深度误判为已保存。
