## 安装与 Windows 集成

- 安装程序静默安装退出码为 0；安装版文件版本与卸载项版本均为 0.3.5。
- `LukePdfEditor.Document`、打开命令、默认图标、`RegisteredApplications`、Capabilities 和缩略图 COM 注册项均存在。
- 打开命令为 `"安装目录\luke-pdf-editor.exe" "%1"`；经 Windows 默认打开链路启动测试 PDF 时，新进程参数包含完整 PDF 路径，窗口可响应并能正常关闭。
- 安装器没有覆盖既有 `UserChoice`。Windows 10/11 仍由用户在系统设置中确认默认 PDF 应用，应用不绕过平台保护直接写受保护字段。

## 已知限制

- 安装包尚未进行 Authenticode 代码签名，Windows 可能显示未知发布者警告。
- Explorer 首页缩略图随鲁科 PDF ProgID 生效；没有将处理器全局强加给用户选择的其他 PDF 阅读器。
- 本轮等效 200% UI 缩放自动化不能替代多显示器、高 DPI、屏幕阅读器和完整 Tab 顺序人工验收。
- GitHub Dependabot 报告的 `glib 0.18.5` 只存在于 Tauri 的 Linux/GTK 目标依赖树；`x86_64-pc-windows-msvc` 依赖树不包含它，因此按 `not_used` 附证据关闭。未来扩展 Linux 发布前必须重新打开并升级或复核。
- 磁盘写满、只读网络路径、异常断电和跨阅读器批注兼容仍是发布门槛；该包不能据此宣称已完整替代 PDF-XChange。
