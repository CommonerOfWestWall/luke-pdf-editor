## 本批实现

- `src/pdf/text-markup.ts`：从 StructuredText 字符 quad 按行合并为 QuadPoints，正向/反向拖选归一为阅读顺序；`rectForQuads` 取外接矩形；`markupContentsPreview` 折叠空白并截断。

- `src/app/App.tsx`：批注工作区启用高亮/下划线/删除线/波浪线四个按钮，按复制权限禁用；创建命令复用 `applyCommand` → 撤销/重做/刷新。
- 评论面板按页分组（`groupAnnotationsByPage`），对标 PDF-XChange Comments 面板组织方式。

## 浏览器开发模式 harness

2026-07-24 回归时复现出 Vite 开发预览选择文件后 `PdfClient.open` 永久等待。根因是 React Strict Mode 会执行一次 effect 的“设置 → 清理 → 重新设置”检查：模块级预热 Worker 在第一次清理中被终止，第二次设置仍复用已终止的实例。

- 预热 Worker 改由 `StandbyClientPool` 按 effect 生命周期创建和销毁；清理后再次 `start()` 必须创建新客户端。
- `src/pdf/standby-client-pool.test.ts` 覆盖 Strict Mode 清理周期，防止再次返回已终止客户端。
- 在 Codex 内置浏览器中通过首页“打开审读 PDF”真实文件选择器重新打开 380 页/253 条批注样本；最终状态为 `busy=false`、无错误、文档标签出现且全文批注数为 253。
- 修复后 `npm run check` 为 23 个测试文件、105 项测试及生产构建通过；同一真实样本的 Tauri E2E 仍为 2 项通过。
