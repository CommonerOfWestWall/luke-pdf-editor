# ADR 0005：整页光栅的内存预算

- 状态：已接受（瓦片渲染前的过渡方案）
- 日期：2026-07-22

## 背景

查看器当前按视口缓冲整页 PNG。若直接使用 `缩放 × devicePixelRatio`，400% 缩放、高 DPI 和 A0 工程图会让单页 MuPDF pixmap 达到数百兆像素；PNG 缓存大小无法约束 Worker 生成阶段和浏览器解码后的峰值内存。

## 决策

- 单页请求最多 1600 万光栅像素，任一边最长 8192 像素。
- CSS 页面尺寸仍使用用户缩放值；达到预算后只降低内部光栅分辨率，因此页面几何、文本、链接和批注覆盖层不变。
- 普通页面与常规 DPR 未触及预算时保持原始请求分辨率。
- 真正的可取消瓦片渲染仍是大图纸和高倍缩放的目标实现，本预算不替代瓦片任务系统。

## 后果

- 同时缓冲多页时，每页 MuPDF pixmap 和浏览器位图具有明确上界。
- 极大页面在高倍缩放下会暂时出现光栅清晰度下降，但矢量文本选择和交互坐标不受影响。
- 性能测试必须包含 A0、400% 与 DPR2，并在瓦片渲染完成后重新评估预算。
