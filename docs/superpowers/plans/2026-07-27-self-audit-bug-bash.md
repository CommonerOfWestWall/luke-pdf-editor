# 当前工作树自查与缺陷清零 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task, and use systematic-debugging for every defect before changing production code.

**Goal:** 以当前未提交工作树为唯一基线，重新验证鲁科 PDF 编辑器的核心工作流，关闭可复现的阻断级和高优先级缺陷，并把仍未通过的能力从“已验证”降级为诚实状态。

**Architecture:** 不新增 PDF 引擎或绕过既有边界。浏览器与 Tauri 实测都通过现有 React → `pdf-client.ts` → Worker 路径；桌面文件与窗口行为继续由 Rust/Tauri 负责。每个缺陷先形成最小复现测试，再做聚焦修复；视觉问题必须以本轮新截图为证据。

**Tech Stack:** React、TypeScript、Vite、Vitest、Zustand、MuPDF.js Worker、Rust、Tauri 2、WebView2
